# Employee Management System - SCM

Software Project Management project demonstrating the Complete Software Configuration Management (SCM) Workflow.

## Project Structure
- src/ - Source code
- docs/ - SPM report and documentation
- config/ - Configuration files
- tests/ - Test cases
- database/ - Database files
- assets/ - Project assets
- screenshots/ - SCM practical screenshots

## Git Commands Used
git --version
mkdir <folder>
cd <folder>
touch <file>
git init
git status
git config --global user.name "..."
git config --global user.email "..."
git config --list
git add .
git add <file>
git commit -m "message"
git log
git log --oneline
git log --oneline --graph --decorate
git branch
git switch <branch-name>
git switch -c <branch-name>
git push -u origin <branch-name>
git pull origin <branch-name>
git merge <branch-name>
git tag -a v1.0 -m "message"
git push origin v1.0
git revert <commit-id>
